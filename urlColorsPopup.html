Defaults

Use 100vw with a low opacity like .05 for a full-screen tint. Individual rules can override these.

URL rules

keyword, color, [flash], [timer], [width], [opacity]
How rules work
  • One rule per line. keyword and color are required.
  • Use * anywhere in the keyword as a wildcard.
  • Add flash as the third value to blink, and timer to set the interval in seconds.
  • Trailing width and opacity values override the defaults above.
  • Values are positional, so use null to skip one — e.g. google.com, blue, null, null, 40px, .9 sets width and opacity without turning on flashing.
