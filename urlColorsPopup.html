Url Keyword Options

Note: Each set of keyword options is on a new line with the format for each being:
keyword, color, [flash], [timer], [border width], [opacity]
Where keyword and color are required.

Note, you may use the wildcard character within the keyword (*)!

If you type in 'flash' as the third word, then the box will blink at the interval set by the optional parameter 'timer'. You can also specify custom border width and opacity values that will override the default values above.
